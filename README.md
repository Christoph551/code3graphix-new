## Usage

To use this application locally on your machine, clone this repo and then install the required dependencies. You can do this by navigating to your CLI and running `npm install`. Note that you'll need to be at the root level of this application.

As a user, you'll be able to browse the many products that Code 3 Graphix has made. Additionally, you'll be able to browse products that you would like to purchase that would be custom engraved with your own ideas coming to life! Have a gift idea for a loved one, select a product from the Orders tab, fill out our short form of how many of the item you wish to purchase, and give us an idea of what you're looking for. You can upload an image to share with us if you have a concept in mind already, or just send a message describing something of what you're thinking of and we'll draw something up within 24 hrs. 

## Contributing

For this project, I utilized a lot of the experiences I learned through my web development bootcamp experience, as well as leaning on ChatGPT, Stack Overflow and YouTube to learn more about some of the dependencies used. For instance, I ran into the issue of React spinning up a server on port 3000 while my backend server needed to run on port 3001. Upon doing some research, I discovered that CORS is a dependency that is for this exact usecase! I was now able to run two servers on my machine and was now able to play with the front-end code to work with my back-end database server.
